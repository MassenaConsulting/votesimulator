Vote Counting Simulator

Academic project. Shows how the chart evolves as ballot boxes arrive, in several scenarios. Base: TSE ballot-box bulletins (President, 2026 and 2022).

Settings

What does each button do?

Start / Pause / Resume
Starts the count. While it runs the button turns into Pause; after pausing it becomes Resume. Use it to watch the chart grow, one update at a time.
Speed up (10x)
Jumps to 10x speed; click again to go back to the speed you had. Use it when you are in a hurry but still want to see the movement. The speed bar sets any speed from 1x to 10x.
Count without animation
Draws the whole count at once. Use it to see the final picture or to compare scenarios quickly.
Restart
Clears the count and starts over with the same settings. Use it to watch it again.
Shuffle
Draws a new random order for the ballot boxes and restarts. Use it to see how luck in the arrival order changes the curve. It only matters in random orders.
Theme
Switches between light and dark colors. Use it when the screen is too bright or too dark.
Use TSE totals
Fills voters, ballot boxes and turnout with the real TSE numbers. Use it to replay a real election at full size.
Show final result (dashed)
Draws dashed lines where each candidate will end. Turn it off to hide the spoiler.

Changing any setting restarts the count by itself.
